# Project instructions

## Badge assets

The user adds badge artwork over time in `public/badges/`. Before working on badges or verification profiles, inspect that folder for the current assets; do not assume the existing list is complete or ask the user to upload files already there.

Preserve supplied filenames and artwork unless the user requests changes. Reference each asset as `/badges/<filename>`. Check for newly added badge files before a requested project push and include relevant supplied artwork. Do not implement verification or badge-assignment features unless requested.
